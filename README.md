# KoW Companion

A mobile-first officer upgrade companion for **Kiss of War**, originally built for **GODS OF WAR 371**.

## Current build

`v3.0.0-beta.1`

## Features

- Officer selection with automatic voucher costs
- Legendary Star I, II, and III calculations
- Officer Development: unlock, skills, and training
- Officer XP Books and level targets
- Goals planner
- Local browser saving
- Custom app name and background
- Installable Progressive Web App
- Offline support after first load

## Publish with GitHub Pages

1. Upload all files in this repository to the `main` branch.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/(root)`.
5. Save and wait for deployment.

Your site will normally be available at:

`https://rogerangliss-byte.github.io/KoW-Companion/`

## Local testing

Open `index.html` directly for basic testing. Service-worker and installation features require an HTTP server or GitHub Pages.

## Data storage

Progress and appearance settings are stored in the browser using `localStorage`. They do not automatically sync between devices.
