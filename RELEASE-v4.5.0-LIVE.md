# KoW Companion v4.5.0 LIVE — Release Notes

**English Live / production release**

v4.5.0 is promoted from the approved English Test build based on the stable v4.4.0 Live baseline.

## Highlights

- Native working-state persistence across refresh for key Officer, Progress, Compare and Planner selections.
- Correct Legendary chest logic: Badge Chests = 1 Universal Legendary Badge OR 600 ORV; Selection Chests = 1 eligible specific Officer Badge only.
- Resource Optimiser preview and Multi-Officer Planner improvements.
- Central Inventory reordered to the approved Order in List 1–89.
- Removed the non-game 50 XP Book entry; supported XP Books are 100, 500, 1,000, 5,000, 10,000, 20,000 and 50,000.
- Updated in-app Help, README and User Guide for v4.5.0.
- Backup/restore and stable v4.4.0 functionality retained.
